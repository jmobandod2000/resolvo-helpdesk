**Resolvo** es una mesa de ayuda de TI open source y autoalojada. Esta es la primera versión pública.

## Instalar

**Solo quiero usarlo:** descarga `resolvo-1.0.0.zip` (Windows) o `resolvo-1.0.0.tar.gz` (Linux/macOS) en *Assets*, descomprímelo y ejecuta dentro de la carpeta:

```bash
resolvo install      # Windows (PowerShell: .\resolvo install)
./resolvo install    # Linux / macOS
```

El único requisito es Docker. El asistente configura todo y al final te muestra la dirección y el usuario administrador.

**Quiero el código:** `git clone https://github.com/jmobandod2000/resolvo-helpdesk.git` y luego `./resolvo install`, o `./resolvo dev` para desarrollar.

Imagen Docker: `ghcr.io/jmobandod2000/resolvo-helpdesk:1.0.0` (amd64 y arm64).

## Qué incluye

- **Tickets** con historial completo, flujo de estados, sedes y categorías configurables, y notas internas o visibles para el solicitante.
- **Portal sin login** para que cualquier persona reporte un problema en 3 pasos y siga su caso con un enlace privado, con avisos por correo.
- **Métricas y reportes** por mes, semana y responsable, con descarga a Excel.
- **Notificaciones** con campanita, sonido y avisos del sistema.
- **IA:** servidor MCP para Claude, Gemini, Codex, Copilot y Cursor.
- **Idiomas:** español, English y português.
- **Operación** con un solo comando: respaldos, restauración, actualización y aviso de nuevas versiones dentro de la app.

Detalle completo en el [CHANGELOG](https://github.com/jmobandod2000/resolvo-helpdesk/blob/main/CHANGELOG.md).
